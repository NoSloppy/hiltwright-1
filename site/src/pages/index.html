Closed beta · Windows · Proffieboard V2.2 and V3

ProffieOS without the compiler.

Hiltwright sets up a Proffieboard saber from wiring to installed firmware. Choose presets, styles and sound fonts, then build and install over USB. No Arduino, no C++, no style code.

Styles

Pick a style. Recolour it live.

Hiltwright comes with dozens of blade styles of its own, each with a live preview. Every colour is editable from the Presets page with no rebuild.

Already have a style you like? Paste its code, from the Fett263 style library or anywhere else, and it keeps its credit.

More about styles

Style editor

Build your own, in blocks or in full.

Simple builds a style from a few plain blocks: a blade, effects on top, an ignition and a retraction. Full shows every ProffieOS layer, and you say what it shows, where on the blade, and when.

The blade beside the editor shows the style as you change it.

Build & Install

A backup before every install.

Install reads the saber's whole firmware into a backup file before it writes anything. "Put back" restores a backup exactly as it was.

The compiler is a one-time download into Hiltwright's own folder. You never open Arduino and never read a config file, unless you are curious.

More about installing

Who it is for

Coming from Crystal Focus X, Xenopixel or LGT?

No toolchain to set up

ProffieOS normally means Arduino, board packages, drivers and a config file in C++. Hiltwright does those parts for you.

Words you already know

Presets, fonts, colours, effects. Each ProffieOS term is explained in a few words where you meet it, and in the glossary.

Hard to get wrong

Wiring must be confirmed before anything is installed. Fonts are checked before they are copied. Every preset change can be undone from History.

Where it stands

Beta 1 is a closed beta for experts.

It is for installers and style builders who own a Proffieboard V2.2 or V3 and run Windows. The installer is not signed, so Windows warns you, and Smart App Control must be off. The install guide covers every step.
